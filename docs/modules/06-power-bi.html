🎯 Learning Objectives

By the end of this module, you will:

  • Build a multi-page Mission Control Dashboard connected to the ZOSA Analytics Model
  • Create an interactive Exoplanet Explorer report for public engagement
  • Apply conditional formatting, bookmarks, tooltips, and slicers
  • Design with a space-themed ZOSA color palette
  • Publish reports to the ZOSA-Dev workspace and pin visuals to a shared dashboard

Chapter 2

1️⃣ Report 1: Mission Control Dashboard

This is Major Nakamura's operational dashboard — the one going up on the big screen in Mission Control. It has three pages, each focused on a different domain.

Connect to the Semantic Model

1
Connect Power BI Desktop
  1. Open Power BI Desktop.
  2. Click Home → Get data → Power BI semantic models.
  3. Select your workspace (ZOSA-Dev) and choose ZOSA Analytics Model.
  4. Click Connect. You should see all your tables and measures in the Fields pane.
No Import Needed

Because you're connecting to a published semantic model, the Direct Lake connection, relationships, and measures are already configured. No data import needed.

Page 1: Executive Overview

This is the "at-a-glance" page — KPIs across the top, charts below.

KPI Cards

Create four Card visuals across the top of the canvas:

CardMeasure / FieldFormat
Total Missions[Total Missions]Whole number
Success Rate[Mission Success Rate]Percentage, 1 decimal
Active Missions[Active Missions]Whole number
Critical Asteroids[Critical Asteroids]Whole number, red callout color

For each card: drag the measure to the canvas, select the Card visual type, set Format → Callout value font size to 28pt. For "Critical Asteroids," set the callout color to red (#FF4444).

Mission Status Donut Chart

1
Configure the Donut Chart

Add a Donut chart visual below the KPI cards (left side).

  • Legend: gold_mission_summary[status]
  • Values: [Total Missions]

In Format → Data colors, assign:

  • Completed → Green (#4CAF50)
  • Active → Blue (#2196F3)
  • Failed → Red (#F44336)
  • Planned → Gold (#FFC107)

Budget by Mission Type (Bar Chart)

2
Configure the Bar Chart

Add a Clustered bar chart (right side, next to the donut).

  • Y-axis: gold_mission_summary[mission_type]
  • X-axis: [Total Budget]

Sort descending by Total Budget. In Format → Data colors, use a gradient from navy (#0D1B2A) to gold (#FFD700).

Slicers

3
Add Slicers
  1. Add a Date range slicer at the top of the page: Field: gold_mission_summary[launch_date], Style: Between (date range picker)
  2. Add a Region dropdown slicer next to it: Field: gold_mission_summary[region], Style: Dropdown
Slicer Placement

Place slicers consistently at the top of every page. Users expect filters in the same location across pages.

Page 2: Asteroid Threat Monitor

This is the page that keeps Major Nakamura up at night.

Threat Scatter Plot

1
Configure the Scatter Chart

Add a Scatter chart as the main visual (top half of the page).

  • X-axis: gold_asteroid_risk[min_miss_distance_au]
  • Y-axis: gold_asteroid_risk[max_relative_velocity_kmps]
  • Size: gold_asteroid_risk[avg_diameter_km]
  • Legend (color): gold_asteroid_risk[risk_category]
  • Tooltips: Add gold_asteroid_risk[name], [Hazard Score]

Apply conditional formatting on the legend:

  • Critical → Red (#FF4444)
  • High → Orange (#FF9800)
  • Medium → Yellow (#FFC107)
  • Low → Green (#4CAF50)
Zoom Sliders

Enable zoom sliders on both axes so analysts can zoom into the cluster of near-miss asteroids.

Top 10 Hazardous Asteroids Table

2
Build the Hazard Table

Add a Table visual (bottom-left) with columns:

  • gold_asteroid_risk[name]
  • gold_asteroid_risk[avg_diameter_km]
  • gold_asteroid_risk[min_miss_distance_au]
  • gold_asteroid_risk[max_relative_velocity_kmps]
  • [Hazard Score]
  • gold_asteroid_risk[risk_category]

Apply a Top N filter: Top 10 by [Hazard Score].

Add conditional formatting on the risk_category column:

  • "Critical" → Red background, white text
  • "High" → Orange background
  • "Medium" → Yellow background
  • "Low" → Green background

Hazard Score Card

3
Add the Hazard Score KPI

Add a Card visual (bottom-right) showing [Max Hazard Score].

Add conditional formatting:

  • If value > 80 → Red
  • If value > 50 → Orange
  • Otherwise → Green

Page 3: Solar Activity Timeline

Space weather data for the science team.

Solar Events Over Time (Line Chart)

1
Configure the Line Chart
  • X-axis: gold_solar_activity[event_month]
  • Y-axis: gold_solar_activity[event_count]
  • Legend: gold_solar_activity[event_type]

Set the X-axis to a continuous date axis (not categorical).

Severity Breakdown (Stacked Column Chart)

2
Configure the Column Chart
  • X-axis: gold_solar_activity[event_type]
  • Y-axis: gold_solar_activity[event_count]
  • Legend: gold_solar_activity[avg_severity]

Color the severity levels: Extreme → Red, Severe → Orange, Moderate → Yellow, Minor → Green.

Latest Events Table

3
Add the Events Table

Columns: event_month, event_type, avg_severity, max_severity.

Apply a Top N filter: Top 15 by event_month (most recent).

Add Tooltips and Interactivity

1
Cross-filtering

Ensure all visuals on each page cross-filter each other (this is the default behavior).

2
Tooltip Pages

Optionally create a tooltip page for asteroids:

  1. New page → set Page size to Tooltip in Format pane.
  2. Add a mini-card with asteroid name, diameter, velocity, and hazard score.
  3. On the scatter chart, set Tooltip → Page to your tooltip page.
3
Drillthrough

Add a drillthrough page for individual mission details:

  1. Create a new page with mission details (launch date, cost, crew, outcomes).
  2. Add gold_mission_summary[mission_id] as a drillthrough field.
  3. Right-click any mission in the donut chart → Drillthrough → Mission Detail.

Chapter 3

2️⃣ Report 2: Exoplanet Explorer

This is the public-facing report — designed for curiosity, not crisis. The public affairs team wants visitors to explore ZOSA's exoplanet catalog interactively.

1
Create a New Report
  1. In Power BI Desktop, go to File → New (or open a new instance).
  2. Connect to the ZOSA Analytics Model the same way as before.

Exoplanet Scatter Plot

2
Configure the Scatter Plot

Add a Scatter chart as the centerpiece of the page:

  • X-axis: gold_exoplanet_catalog[orbital_period_days] (consider log scale)
  • Y-axis: gold_exoplanet_catalog[planet_mass_earth]
  • Legend (color): gold_exoplanet_catalog[discovery_method]
  • Tooltips: gold_exoplanet_catalog[planet_name], gold_exoplanet_catalog[host_star], gold_exoplanet_catalog[distance_ly], gold_exoplanet_catalog[habitability_zone]

Enable zoom sliders on both axes. Set axis scaling to Logarithmic for orbital period (values span many orders of magnitude).

Filter Panel

Add the following slicers in a vertical panel on the left side:

SlicerFieldStyle
Habitable Zonegold_exoplanet_catalog[habitability_zone]Toggle (Yes/No buttons)
Discovery Yeargold_exoplanet_catalog[discovery_year]Between (range slider)
Distance (ly)gold_exoplanet_catalog[distance_ly]Between (range slider)
Discovery Methodgold_exoplanet_catalog[discovery_method]Dropdown (multi-select)
Filter Panel Design

Group the slicers inside a rectangle shape with a subtle background (#0D1B2A at 80% transparency) to create a clean filter panel effect.

Planet Detail Card

3
Multi-row Card

Add a Multi-row card visual on the right side with fields:

  • planet_name, host_star, discovery_method, discovery_year
  • planet_mass_earth, orbital_period_days, distance_ly
  • habitability_zone, planet_radius_earth

This card updates dynamically when you click a dot on the scatter plot.

Bookmarks for Preset Views

4
Bookmark 1: "Habitable Candidates"
  1. Set the Habitable Zone slicer to Yes.
  2. Optionally filter distance to < 100 light-years.
  3. Go to View → Bookmarks pane → Add bookmark.
  4. Name it 🌍 Habitable Candidates.
5
Bookmark 2: "Recent Discoveries"
  1. Set the Discovery Year slicer to the last 5 years.
  2. Clear all other filters.
  3. Add bookmark → Name it 🔭 Recent Discoveries.
6
Add Bookmark Navigation Buttons
  1. Go to Insert → Buttons → Navigator → Bookmark navigator, or add manual buttons.
  2. Add two Blank buttons at the top of the page.
  3. Label them "🌍 Habitable Candidates" and "🔭 Recent Discoveries".
  4. In Format → Action, set type to Bookmark and select the corresponding bookmark.
Bookmarks Explained

Bookmarks capture the state of all slicers, filters, and visual selections. They're like "saved searches" that let users explore without getting lost.

3️⃣ Design Tips — The ZOSA Look

Both reports should feel like they belong in a space agency. Here's the ZOSA design system:

Color Theme

RoleColorHex
Background (primary)Deep Space Navy#0D1B2A
Background (secondary)Dark Slate#1B2838
Accent (primary)ZOSA Gold#FFD700
Accent (secondary)Nebula Blue#2196F3
Text (primary)White#FFFFFF
Text (secondary)Silver#B0BEC5
Alert / CriticalRed#FF4444
SuccessGreen#4CAF50
WarningOrange#FF9800

Apply the Theme

Create a JSON theme file (zosa-theme.json):

zosa-theme.json 
{
  "name": "ZOSA Mission Control",
  "dataColors": [
    "#FFD700", "#2196F3", "#4CAF50", "#FF9800",
    "#FF4444", "#9C27B0", "#00BCD4", "#E91E63"
  ],
  "background": "#0D1B2A",
  "foreground": "#FFFFFF",
  "tableAccent": "#FFD700"
}

In Power BI Desktop: View → Themes → Browse for themes → select your JSON file.

Typography

  • Titles: Segoe UI Semibold, 14pt, White
  • Labels: Segoe UI, 10pt, Silver (#B0BEC5)
  • KPI values: Segoe UI Bold, 28pt, Gold (#FFD700)

Mobile Layout

Field scientists need data on their tablets in remote locations.

1
Configure Mobile Layout
  1. Go to View → Mobile layout.
  2. Drag the most critical visuals to the phone canvas:
    • Page 1: KPI cards + Mission Status donut
    • Page 2: Hazard Score card + Top 10 table
    • Page 3: Solar Events line chart
  3. Resize visuals to fit the portrait aspect ratio.
Mobile Layouts

Mobile layouts are separate from the desktop layout — you can choose which visuals to show on mobile without affecting the desktop experience. Prioritize the "need-to-know" visuals for field use.

Chapter 5

4️⃣ Publish to Workspace

Time to get these reports off your machine and into the hands of the team.

Publish from Power BI Desktop

1
Publish Both Reports
  1. For each report, go to File → Publish → Publish to Power BI.
  2. Select the ZOSA-Dev workspace.
  3. Click Select. Wait for the upload to complete.
  4. You'll see a success message with a link to open the report in the service.

Verify in the Service

2
Verify in the Fabric Portal

Open the Fabric portal → Navigate to ZOSA-Dev workspace. Confirm you see:

  • Mission Control Dashboard (report)
  • Exoplanet Explorer (report)
  • Both reports should be connected to ZOSA Analytics Model (no duplicate datasets).
No Duplicate Datasets

Because you connected to the published semantic model, no new dataset is created when you publish. Both reports share the same Direct Lake model — exactly as designed.

Pin to a Shared Dashboard

3
Create the ZOSA Mission Control Dashboard
  1. Open the Mission Control Dashboard report in the service.
  2. Hover over the Mission Success Rate KPI card → click the 📌 Pin icon.
  3. Select New dashboard → Name it ZOSA Mission Control.
  4. Pin additional visuals: Mission Status donut chart, Critical Asteroids KPI card, Hazard Score card, Solar Events line chart.
  5. Arrange tiles on the dashboard by dragging and resizing.
Dashboards vs Reports

Dashboards are a Power BI service concept — they combine pinned visuals from multiple reports onto a single canvas. Think of them as a curated "highlights reel."

Verify RLS
  1. Open the Mission Control Dashboard report in the Fabric portal.
  2. Click ⋯ (More options) → Security → View as role.
  3. Select a role (e.g., "Regional Analyst — Americas").

RLS Not Filtering?

If RLS isn't filtering, go back to Module 05 and verify your role definitions and DAX expressions on the ZOSA Analytics Model.
