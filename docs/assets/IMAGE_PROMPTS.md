## 🎨 Style Guide for Consistency

When generating all images, add these style modifiers:
- **Color palette:** Deep navy (#0a0e27), cyan (#00d4ff), purple (#8b5cf6), white highlights
- **Lighting:** Soft ambient with directional rim lights
- **Style:** Clean sci-fi, NOT gritty/dystopian — think optimistic space exploration
- **Quality:** `--quality 2` (Midjourney) or "high quality, detailed" (DALL-E)
- **Negative prompts:** No text, no watermarks, no logos, no cluttered backgrounds
