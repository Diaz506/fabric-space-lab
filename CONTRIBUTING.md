# Contributing to Fabric Space Lab

Thanks for your interest! Here's how you can help:

## 🐛 Found a Bug?

Open an issue describing the problem, which module it affects, and steps to reproduce.

## 💡 Suggesting Improvements?

Open an issue with the `enhancement` label. Describe what you'd change and why.

## 🔧 Submitting a PR?

1. Fork the repo
2. Create a feature branch (`git checkout -b fix/module-04-typo`)
3. Make your changes
4. Ensure all data scripts still run: `python data/generate_synthetic.py`
5. Submit a PR with a clear description

## 📝 Style Guide

- Lab modules use **second person** ("You will create...") for instructions
- Story sections use **narrative voice** in blockquotes
- Code blocks include the language identifier (```python, ```sql, ```kql)
- Screenshots go in `assets/screenshots/<module-number>/`

## 🌟 Code of Conduct

Be kind, constructive, and inclusive. We're all here to learn.
